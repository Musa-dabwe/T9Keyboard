Bug

Query underline ignores the user's accent

emoji_search_panel.xml: emoji_search_underline background is hard-coded #E91E63 (magenta) regardless of the accent color chosen in Settings — every other "active" indicator in the app (anchored suggestion, active SHIFT, active xt9 chip) follows the user's accent, so this one stands out as inconsistent.

Bug

Search keys use a different shape language

EmojiSearchKey style + emoji_search_key_bg.xml use a flat #111111 fill with 10dp corners — the main grid's keys are 16dp on a #0D0D0D surface with a hairline border. This mockup already applies the 16dp/bordered treatment for comparison.
