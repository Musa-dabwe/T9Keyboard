03 · Symbols page (SYM)

Rebuilt from symbols_view.xml + SymbolsView.kt's hardcoded 40-symbol list, an 8-column × 5-row GridLayout reached via the SYM key.

Bug

Top bar background never updated

keyboard_view.xml's topBar background was already switched to @color/keyboard_background in this pass, but its corner radius language differs from the main grid: symbol cells use a plain ripple (symbol_cell_background) with no key surface, border, or 16dp radius at all — so this panel reads as a different, flatter component than the letters/numbers grid it's one tap away from.

Proposed

Give symbol cells the same key language

Wrap each symbol in the same key_surface + hairline border + 16dp radius used everywhere else, so SYM reads as "the same keyboard, more characters" rather than a distinct settings-style list.
